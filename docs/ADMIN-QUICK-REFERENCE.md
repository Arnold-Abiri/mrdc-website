# Administrator Quick Reference (day-to-day)

- **Publish news**: News and notices → Create → type News → fill → Verify (publishable) → Publish.
- **Publish notice**: same, type Notice + expiry date (+ Urgent for the banner).
- **Upload/replace document**: Documents → Create (PDF, category, reference year) → verify → Publish. To supersede: row action **Replace file** (history kept, back to draft).
- **Publish tender**: Tenders → Create (reference, dates, document) → verify → Publish. Close happens by date; **Record award** with cleared details only.
- **Publish vacancy**: Vacancies → Create (dates, advert) → verify → Publish. Expired reads Closed — never republish old adverts.
- **Update official**: Officials → edit → save returns to draft → re-verify → Publish.
- **Update contact**: Public contacts → edit (feeds homepage, contact + department pages).
- **Manage project**: Projects → edit fields/wards/documents → updates via Project updates → verify → Publish.
- **View enquiry/feedback**: Enquiries → open → internal note / status / route / assign (all audited).
- **Translation status**: Translation status page → complete missing sn/nd with approved wording.
- **M&E report**: M&E dashboard → set period → read KPIs/trends; Monthly report → print/CSV.

Rule of thumb: if citizens should see it, it must be Verified **and** Published. Editing published work returns it to draft — re-verify before it reappears.
