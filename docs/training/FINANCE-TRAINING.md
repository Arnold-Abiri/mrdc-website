# Finance Training Track (2 staff)

The website **publishes approved financial information**. It is not the
council's accounting or ERP system: no ledgers, payments, reconciliations,
or payroll exist here. Finance staff manage disclosure documents only.

## Modules (in the training environment)

1. **Financial documents** (`Documents` resource): create a draft with
   category Budget / Financial statement / Financial report / Procurement plan
   / Awards register; set the applicable **reference year** (reporting year,
   not upload year); attach the approved PDF; link the department.
2. **Verification lifecycle**: Draft → Verified/Publishable → Published.
   Editing a published item returns it to draft for re-review.
3. **Replacement vs new document**: use **Replace file** when a schedule is
   superseded (history preserved, version incremented, back to draft).
   Create a new document only for a genuinely different publication.
4. **Tender awards**: record contractor, date, reference, amount **only if
   council has approved publication**, plus award document/remarks.
5. **Rates schedules**: rates information page + linked schedule documents;
   never publish private ratepayer account data.
6. **Transparency page**: confirm items appear under `/transparency` with
   correct year/category filters after publication.
7. **Download reporting**: M&E dashboard → most downloaded documents.
8. **Audit trail**: every publish/replace/award action is attributed; audit
   records must not be altered to hide mistakes.

## Common mistakes
Publishing before verification; using upload year instead of the applicable
year; creating a duplicate instead of replacing; entering award amounts not
cleared for publication.
